# OSB Company Scraper

Python ile Turkiye'deki Organize Sanayi Bolgelerinde bulunan firma bilgilerini toplamak icin gelistirilmis web scraping projesidir.

## Features

- Firma adı toplama
- Sektor bilgisi toplama
- Telefon numarası toplama
- E-mail adresi toplama
- Web sitesi bilgisi toplama
- Turkce karakter normalizasyonu
- Google Sheets entegrasyonu

## Technologies

- Python
- Requests
- BeautifulSoup
- Google Sheets API
